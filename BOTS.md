# Демо-бот «Наш дом. Медиа» × NeuraLead (Telegram + MAX)

Открытый ИИ-бот двух компаний и живой пример для бизнеса.

- Отвечает на свободный текст: реклама в лифтах Удомли, QR-коды, ИИ-боты, связка «Реклама + заявки».
- Считает стоимость размещения точно по прайсу (`knowledge.py`), а не «на глаз».
- Кнопка **«🎭 Показать на моём бизнесе»**: человек называет свой бизнес, и бот разыгрывает, как отвечал бы его клиентам. Выход — кнопка или слово «выход».
- Заявки сохраняются в базу и сразу приходят менеджеру в Telegram. Команда `/leads` показывает последние 10, работает только для `ADMIN_CHAT_ID`.
- Telegram и MAX работают в одном процессе (`run_bots.py`), поэтому двойных ответов нет.

## Файлы

| Файл | Что внутри |
|---|---|
| `knowledge.py` | **Цены, зоны, скидки, тарифы ботов, контакты.** Меняете прайс только здесь. Файл такой же в репозитории `neuralead-bot`. |
| `demo_brain.py` | Логика диалога: ассистент и демо-режим |
| `run_bots.py` | Подключение к Telegram и MAX |
| `llm.py` | Запросы к Polza AI с запасными моделями |
| `storage.py` | База SQLite: переписка, заявки, состояние чатов |
| `tests/` | Проверка логики без интернета: `python -m unittest discover -s tests` |

## Переменные окружения на хостинге

| Переменная | Обязательно | Что это |
|---|---|---|
| `POLZA_API_KEY` | да | ключ Polza AI |
| `BOT_TOKEN` | для Telegram | токен бота от @BotFather |
| `ADMIN_CHAT_ID` | да | ваш Telegram ID, сюда приходят заявки |
| `MAX_BOT_TOKEN` | для MAX | токен бота MAX |
| `MAX_ADMIN_USER_ID` | нет | ваш ID в MAX, если заявки из MAX нужны в MAX |
| `LLM_MODELS` | нет | модели через запятую, по умолчанию `google/gemini-2.5-flash,deepseek/deepseek-v4.1-flash,anthropic/claude-haiku-5.5` |
| `DATA_DIR` | нет | папка базы, по умолчанию `data`; **на хостинге сделайте её постоянной** |
| `NASHDOM_PHONE`, `NEURALEAD_PHONE` и др. | нет | контакты, если поменяются (список в `knowledge.py`) |

## ⚠️ Токен MAX

В старой версии (`bot_max.py`) токен MAX-бота был записан прямо в коде открытого репозитория и остался в истории GitHub. **Выпустите новый токен в кабинете MAX** и впишите его в `MAX_BOT_TOKEN` на хостинге. Новая версия берёт токен только из переменной.

## Запуск

`bash start.sh` запускает генератор сайтов (если задан ключ Polza) и бота (если задан `BOT_TOKEN` или `MAX_BOT_TOKEN`).
